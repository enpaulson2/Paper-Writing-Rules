# Paper Writing Rules

Central reference library for reusable academic manuscript-writing standards and paper-specific editorial rules.

## Organization

- `General_IEEE_Writing_Rules.md` — reusable IEEE language, literature review, referencing, technical writing and validation standards.
- `IoT_Journal/Adaptive_Block_SCA_Writing_Rules.md` — rules for *Adaptive Block SCA for Resource Optimization in Multibeam LEO Satellite–Terrestrial Networks*.
- Future journal-specific rules can be added under `TWC/`, `TCOM/`, `TAES/`, and other suitable folders.

## Rule priority and use

Paper-specific rules supplement general IEEE rules. Scientific evidence and the latest explicit author instructions take precedence over illustrative wording from accepted papers. Before editing a manuscript, consult the applicable paper-specific rulebook and relevant journal instructions.

## Source manuscripts

The initial rules were derived from two accepted IEEE Internet of Things Journal manuscripts, the DRL project's IEEE-formatted bibliography, and reviewer-identified issues in the Adaptive Block SCA manuscript.

Do not copy results, equations, or technical claims from a style reference into another manuscript without valid scientific provenance.
